# GunSword - Custom Systems Documentation

This directory contains documentation for all custom systems built for the GunSword project. Each system is designed to be modular and reusable.

## Systems

| System | File | Description |
|---|---|---|
| [MultiViewAnimatedSprite3D](multiview-animated-sprite-3d.md) | `entities/multi_view_animated_sprite_3d.gd` | Directional billboarded sprite with layer compositing and PBR shading |
| [Multi-View Entity PBR Shader](multi-view-entity-pbr-shader.md) | `shaders/multi_view_entity_depth.gdshader` | Spatial shader for PBR on sprite-based entities |
| [EntityStatusBar](entity-status-bar.md) | `entities/entity_status_bar.gd` | Modular health/status bar for any entity |
| [FrustumCamera3D](frustum-camera-3d.md) | `player/frustrum_camera_3d.gd` | View-frustum culling for performance |
| [Simple Scatter](simple-scatter.md) | `addons/simple_scatter/` | Foliage/object scattering with density control |
| [EnvGlobal](env-global.md) | `scripts/env_global.gd` | Global environment configuration and scatter density |
